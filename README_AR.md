# Chess Lab — مشروع شطرنج محلي

## التشغيل على ويندوز
1. ثبّت Python 3 من https://www.python.org/downloads/ مع Python Launcher وTcl/Tk.
2. فك ضغط المشروع.
3. افتح start_windows.bat. يحتاج الإنترنت في التشغيل الأول لتثبيت مكتبة قوانين الشطرنج.

أو افتح الطرفية داخل المجلد:
```
python -m pip install -r requirements.txt
python app.py
```
على Linux تحتاج حزمة python3-tk حسب التوزيعة.

## الاستخدام
- اسحب القطعة بالماوس واتركها فوق الوجهة، أو اضغط القطعة ثم مربع الوجهة. النقاط توضح الوجهات القانونية. النقلات غير القانونية أو الإفلات خارج الرقعة يرجع القطعة إلى مكانها.
- New game: مباراة جديدة، يمكنك إدخال نقلات الطرفين.
- يظهر سهم الاقتراح تلقائيًا عند فتح البرنامج وبعد كل نقلة أو تراجع أو مباراة جديدة. انتظر انتهاء زمن التفكير المختار. الطرف السفلي ينفذ نقلة المحرك تلقائيًا بعد التحليل، والطرف العلوي تحركه أنت بالسحب أو النقر. قلب الرقعة يبدل الطرف التلقائي حسب الموجود تحت. ويختفي الاقتراح القديم فور تغيير الوضعية.
- خلفية الرقعة أزرق فاتح وداكن؛ القطع البيضاء والأسود بحدود متباينة لتوضيحها.
- يمكن تكبير وتصغير النافذة؛ الرقعة والقطع تتكيف مع الحجم. أصغر حجم 650×560 للحفاظ على ظهور عناصر التحكم.
- نقلة الطرف السفلي تُنفذ تلقائيًا؛ لم يعد هناك زر لتنفيذها يدويًا.
- Undo: يرجع إلى دور الطرف اليدوي، وقد يتراجع نقلتين لمنع إعادة نفس الرد التلقائي. Flip board: يعكس اتجاه الرقعة.
- عند الترقية اختر Q أو R أو B أو N.
- Export PGN: يحفظ المباراة لإعادة التحليل أو تسليمها.
- اختَر زمن التفكير 1 أو 3 أو 5 أو 10 ثوانٍ. النتيجة تعود من آخر عمق مكتمل.

## تصميم المشروع
app.py: واجهة Tkinter، إدخال النقلات والرسم والسهم، وتحليل في خيط منفصل.
engine.py: محرك مستقل مكتوب لهذا المشروع؛ لا يستدعي Stockfish أو أي محرك خارجي.
requirements.txt: مكتبة chess لقواعد اللعبة والنقلات القانونية وكتابة PGN فقط.

البحث: Negamax وAlpha-Beta، تعميق تدريجي، بحث هادئ في الأخذ والترقية،
ومعالجة إجبارية لردود الكش أثناء البحث الهادئ مع حد أقصى لمنع البحث غير المحدود.
ترتيب النقلات: النقلة السابقة الأفضل، ثم الأخذ حسب قيمة القطع والترقية.
جدول التخزين يضم تاريخ النقلات لعدم مشاركة تقييمات التعادل عبر مسارات مختلفة.
التقييم: قيمة القطع، تمركزها، نشاط الفيل والحصان، زوج الفيلة، البيادق المعزولة
والمضاعفة والمارة، الأعمدة المفتوحة للرخ، وحماية الملك وتحريكه في النهاية.

## حدود النسخة
هذه نسخة تعليمية تعمل، وليست محركًا مقاس القوة. تصنيف 2000 هدف تطوير وليس
نتيجة مثبتة؛ الوصول إليه يحتاج اختبارات مباريات كثيرة بنفس زمن اللعب وأجهزة
محددة وتحسينات لاحقة. التقييم ليس احتمال فوز ولا تقييمًا صادرًا من Stockfish.
حد الزمن تقريبي ويُراجع على فواصل أثناء البحث.
الواجهة باللغة الإنجليزية لضمان عرض النص جيدًا في Tkinter، وهذا الدليل عربي.
لا يوجد اتصال بمواقع لعب أو استيراد مباشر للمباريات أو خصائص إخفاء المساعدة.
التعادل بالثلاث تكرارات يعامل كتعادل في البحث؛ قواعد نهاية المباراة على الرقعة
تستخدم النهايات التلقائية، دون واجهة منفصلة للمطالبة بالتعادل.
